Diagrama de clases

¿Qué elementos componen el sistema?

¿Qué representa?

El diagrama de clases muestra la estructura del sistema. Cada clase agrupa datos y operaciones relacionados.

  • Atributos: datos que describen la clase.
  • Métodos: acciones que puede realizar.
  • Relaciones: conexiones entre clases.

Clases propuestas

  • Usuario: id, nombre, correo.
  • Libro: código, título, disponibilidad.
  • Préstamo: fechaPréstamo, fechaDevolución, estado.
  • Bibliotecario: id, nombre.
Importante: es un modelo simplificado para practicar; puedes ampliarlo según los requisitos.

TU TURNO

Actividad en Lucidchart

  1. Abre una nueva página y selecciona un diagrama de clases UML.
  2. Crea las clases Usuario, Libro, Préstamo y Bibliotecario.
  3. Divide cada clase en nombre, atributos y métodos.
  4. Conecta las clases: el usuario solicita préstamos, el préstamo se asocia con un libro y el bibliotecario registra la operación.
  5. Agrega nombres a las asociaciones y, si lo has estudiado, indica multiplicidades como 1 y 0..* donde correspondan.
  6. Comprueba que el diagrama sea coherente con los casos de uso.
Producto esperado: un diagrama que muestre clases, atributos, métodos y relaciones principales.
