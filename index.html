Diagrama de casos de uso

¿Quién usa el sistema y qué puede hacer?

Situación del problema

Una biblioteca necesita un sistema para que los usuarios consulten libros y soliciten préstamos. El bibliotecario registra los préstamos y las devoluciones. Antes de prestar un libro, se verifica que el usuario esté registrado y que el ejemplar esté disponible.

Actores y funciones

  • Usuario: consultar catálogo y solicitar préstamo.
  • Bibliotecario: registrar préstamo y devolución.
  • Sistema: validar el registro y la disponibilidad.
Recuerda: los actores se dibujan fuera del límite del sistema y los casos de uso se representan con óvalos dentro del rectángulo.

Ejemplo visual

Esquema de referencia: conecta cada actor con las funciones en las que participa.

TU TURNO

Actividad en Lucidchart

  1. Crea un documento nuevo y selecciona una plantilla UML de casos de uso.
  2. Dibuja y nombra el límite del sistema: Sistema de biblioteca.
  3. Añade los actores Usuario y Bibliotecario.
  4. Incluye los casos de uso: consultar catálogo, solicitar préstamo, registrar préstamo y registrar devolución.
  5. Conecta cada actor con las funciones correspondientes.
  6. Si separas la validación de usuario y disponibilidad como casos de uso, relaciónalos con “Solicitar préstamo” mediante <<include>>.
Producto esperado: un diagrama legible con título, actores, límite del sistema, óvalos y relaciones.
