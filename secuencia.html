Solicitar un préstamo

Representaremos el orden de los mensajes entre el usuario, la interfaz, el sistema y la base de datos durante una solicitud.

Diagrama de secuencia

¿Qué sucede primero y qué sucede después?

Escenario

El usuario selecciona un libro y solicita el préstamo. El sistema comprueba que el usuario esté registrado y que el libro esté disponible. Si todo es correcto, registra el préstamo y muestra una confirmación.

Participantes

  • Usuario: inicia la solicitud.
  • Interfaz: recibe la acción y muestra el resultado.
  • Sistema de biblioteca: valida y procesa.
  • Base de datos: consulta y guarda información.

Orden de los mensajes

  1. El usuario selecciona “Solicitar préstamo”.
  2. La interfaz envía la solicitud al sistema.
  3. El sistema consulta usuario y disponibilidad.
  4. La base de datos devuelve los resultados.
  5. El sistema registra el préstamo.
  6. La interfaz muestra la confirmación.
Recuerda: el tiempo se representa de arriba hacia abajo y las flechas indican mensajes entre participantes.

TU TURNO

Actividad en Lucidchart

  1. Crea una página nueva y selecciona un diagrama de secuencia UML.
  2. Coloca cuatro participantes: Usuario, Interfaz, Sistema de biblioteca y Base de datos.
  3. Dibuja sus líneas de vida verticales.
  4. Agrega los mensajes en el orden del escenario.
  5. Representa las respuestas que regresan al participante que hizo la solicitud.
  6. Añade una alternativa: ¿qué sucede si el libro no está disponible? Muestra que el sistema informa al usuario y no registra el préstamo.
Producto esperado: un diagrama de arriba hacia abajo que explique la solicitud y la respuesta del sistema.
